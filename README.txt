ARNOLD OKELO PORTFOLIO — QUICK START

FILES
- index.html: Home page
- about.html: About, programming skills and progress
- projects.html: Project cards and category filters
- style.css: Shared responsive dark theme
- script.js: Mobile menu, current year and project filters

OPEN THE SITE
Open index.html in your editor/browser. Keep all five files in the same folder.

IMPORTANT: PERSONALISE THESE PLACEHOLDERS
1. Search all HTML files for YOUR_EMAIL@gmail.com and replace it with your actual email.
2. Replace +254 7XX XXX XXX and tel:+254700000000 with your actual phone number.
3. Edit the skill percentages in about.html so they reflect your real progress.
4. In projects.html, replace placeholder links with your GitHub repository and deployed demo URLs.
5. Project cards currently describe sample/learning projects. Keep only the ones you have actually built, or label the others as planned/in progress.

LAPTOP BACKGROUND
The hero currently uses a remote laptop photo from Unsplash. It is a general laptop photo, not guaranteed to be a Lenovo model. For an exact Lenovo image, put your legally usable image in this folder as lenovo-laptop.jpg and replace the image URL in style.css with:
url('lenovo-laptop.jpg')
There are two hero background declarations in style.css (desktop and mobile), so update both.

HOW TO ADD A PROJECT
Copy one <article class="project-card" ...> card in projects.html, change its title, description, tags, category, and links. Use data-category="web", "backend", or "planned" so the filter works.
